## Short Description 

A 2D modeling and simulation tool for designing woven structures, assigning mechanical and physical properties, and approximately predicting their mechanical behavior.

## About the Project 

This software allows users to create and model a 2D representation of a weave structure including its cross section and define relevant mechanical and physical properties. Based on the modeled geometry and assigned properties, the software aims to provide approximate predictions of the weave's mechanical behavior and generate useful mechanical plots.

## 🚧 Under development

The initial versions will focus on 2D weave modeling, property assignment, and approximate mechanical predictions. Accuracy and modeling capabilities will be improved as the underlying models are developed and validated.

## Disclaimer 

The predicted mechanical properties are approximate and should not be considered a replacement for experimental testing or validated high-fidelity simulation methods.
